  1. Crear la carpeta en el nostre disc dur, treballem en local.
  2. Obrim el programa Visual Studio Code, arrastrar la carpeta al explorador o open folder
  3. Crear new file: index.html
  4. Editem el fitxer
  5. Obrim el navegador y accedim nostre perfil de github
  6. Crearem un repositori com per exemple el repositori p1
  7. Add files i upload files
  8. Una vegada el archiu index.html apareix en el directori del nostre repositori, anem a settings, en la barra de l´esquerra busquem pages i en el github pages camviem nome a main i apretem save
  9. Esperem un poc i actualitzem i ens apareixera la nostra url del depositori publicat en format webpage
